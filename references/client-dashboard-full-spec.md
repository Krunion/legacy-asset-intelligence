# Client Executive Dashboard - Full Specification

## Navigation Menu:
- Dashboard (executive summary)
- Project Progress
- Assets (Verification, Reconciliation)
- Recovery Opportunities
- Risks and Exceptions
- Locations
- Tasks and Approvals
- Reports and Documents
- Meetings and Messages
- Billing
- Settings (password change)

## Key Rules:
- NEVER show internal costs, contractor rates, profit margins, staffing expenses
- Role-based access (7 roles)
- Action buttons: Review, Approve, Reject, Respond, Upload, Assign, Mark Complete
- Financial status progression: Preliminary → Under review → Client validated → Approved → Realized
- Dashboard changes based on active phase

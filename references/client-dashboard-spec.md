# Client Executive Dashboard Specification

## Navigation Menu
Dashboard, Project Progress, Assets, Verification, Reconciliation, Recovery Opportunities, Risks and Exceptions, Locations, Tasks and Approvals, Reports and Documents, Meetings and Messages, Billing, Users and Permissions, Support

## 14 Sections

### 1. Executive Overview
- Client organization name and logo
- Active LAI engagement, Current project phase
- Overall project status: On Track, At Risk, or Delayed
- Percentage complete, Engagement start date, Target completion date, Days remaining
- LAI project manager, Client project lead
- Date and time data was last updated

### 2. Key Performance Indicators
- Total assets in FAR, Assets reviewed, Assets physically verified, Assets remaining
- Verification completion percentage
- Assets matched to FAR, Assets not found, Assets found but not recorded
- Duplicate asset records, Assets requiring further investigation
- Estimated hidden/lost capital identified, Verified capital-recovery opportunities
- Potential annual cost savings, Open high-risk exceptions
- Financial status: Preliminary estimate, Under review, Client validated, Approved for action, Actual realized

### 3. Project Phase Tracker (4 phases)
- Discovery and Executive Assessment
- Physical Verification and Recovery Analysis
- Technology Implementation and Enablement
- Recurring Governance and Executive Advisory
- Each: status (Not Started/In Progress/Completed/On Hold), completion %, activities, milestones, dates, deliverables

### 4. Asset Verification Summary
- Total scheduled, Verified, Unverified, Matched, Missing, Ghost, Unrecorded, Duplicates
- Wrong location, Incorrect custodian, Incorrect descriptions
- Condition/Utilization classifications, Pending photos, Pending client clarification
- Filters: Location, Department, Category, Custodian, Status, Condition, Utilization, Risk, Date

### 5. Financial Recovery Dashboard
- Total potential recovery, Client-validated, Actual realized
- Avoided replacement costs, Sale/disposal proceeds, Insurance/tax exposure
- Maintenance/licensing elimination, Idle capital, Redeployment assets, Disposal recommendations
- ROI, Return multiple, 3-year projection
- Status per opportunity: Identified, Under Investigation, Awaiting Validation, Approved, In Progress, Realized, Rejected, Closed

### 6. Risk & Exception Management
- High-value missing assets, No custodian, Uninsured, No documentation
- Unauthorized locations, Duplicate purchases, Obsolete equipment
- Cybersecurity concerns, Compliance exceptions, Pending decisions
- Each: Risk level, Asset, Location, Financial exposure, Recommended action, Responsible party, Due date, Status

### 7. Locations & Departments
- Total locations, Completed, In review, Not started
- Completion % by location, Assets verified per location
- Exceptions by location, Recovery opportunities by location
- Department-level completion and findings
- Map for regional/multistate/national clients

### 8. Action Center (items waiting on client)
- Documents requiring approval, Questions from LAI, Assets requiring clarification
- Milestones requiring acceptance, Change orders, Meetings requiring confirmation
- Corrective actions assigned, Overdue tasks, Upcoming deadlines
- Buttons: Review, Approve, Reject, Respond, Upload Document, Assign, Mark Complete

### 9. Reports & Deliverables
- Executive Assessment, Verification Analysis, Reconciled FAR, Discrepancy matrix
- Inventory Master Log, Recovery Opportunity Register, Governance scorecards
- Risk/exception reports, Location reports, Asset photographs
- Meeting summaries, Final presentations, Technology plans, Quarterly reports
- Show: version, date published, approval status, final/draft

### 10. Meetings & Communications
- Upcoming meetings, Recent summaries, Decisions made
- Questions awaiting response, Project announcements
- LAI contact information, Secure messages

### 11. Phase 3 Implementation (when purchased)
- Implementation partner (Asset Panda), Configuration progress
- Data cleansing, FAR migration, Tagging progress (if included)
- Barcode assignment, User accounts, Workflow config, Dashboard config
- System integrations, Training, UAT, Go-live date, Post-launch issues

### 12. Phase 4 Governance
- Governance maturity score, Previous/current levels
- Open exceptions, Audit schedule, Upcoming verification dates
- Assets added/transferred/disposed since last review
- Overdue acknowledgements, Policy compliance, Quarterly trends
- Recurring savings, Executive recommendations, Next QBR

### 13. Billing & Engagement
- Contracted services, Current engagement value
- Invoices, Amount paid, Outstanding balance, Upcoming payments
- Change orders, Approved additional services, Contract/SOW documents
- NEVER show: internal costs, contractor rates, profit margins, staffing expenses

### 14. User Permissions (roles)
- Executive Sponsor: All executive, financial, project, report info
- Client Project Lead: Project activity, tasks, assets, documents, communications
- Finance User: FAR reconciliation, financial opportunities, invoices, reports
- Department Manager: Assets/exceptions for their department
- Location Manager: Info limited to assigned locations
- Read-Only User: Approved dashboards and final reports only
- External Auditor: Selected records, evidence, compliance reports
